2. COMPILER SUR OVERLEAF
======================================================================

1. Connectez-vous à Overleaf.
2. Cliquez sur "New Project", puis "Upload Project".
3. Sélectionnez l'archive Module_Django_GesiBiblio.zip.
4. Ouvrez main.tex.
5. Ouvrez l'icône Réglages (roue dentée, à gauche), onglet Compiler,
   et réglez "Compiler" sur XeLaTeX ou pdfLaTeX. Les deux fonctionnent ;
   XeLaTeX est recommandé.
6. Cliquez sur Recompile. Compilez deux fois pour que la table des
   matières et les numéros de page soient à jour.

Le document compile aussi en local avec Tectonic, XeLaTeX ou pdfLaTeX.
Commande locale possible :

  tectonic -X compile main.tex

ou

  latexmk -pdf main.tex

======================================================================
3. COMPILER EN LOCAL
======================================================================

Prérequis : une distribution LaTeX récente (TeX Live 2023 ou plus,
MiKTeX, MacTeX) avec les paquets courants.

  pdflatex main.tex
  pdflatex main.tex

ou

  xelatex main.tex
  xelatex main.tex

En cas de paquet manquant avec TeX Live :

  tlmgr install tcolorbox fontawesome5 tabularx booktabs titlesec

6. COMPILER RAPIDEMENT SUR OVERLEAF
======================================================================

Le plan gratuit d'Overleaf limite chaque compilation a 10 secondes.
Le module complet depasse 200 pages : il ne peut pas tenir dans ce
delai, meme en mode brouillon. Le message "Your project needs more
compile time" vient de cette limite, pas d'une erreur du document.

Trois solutions :

1. Lire le PDF deja compile : Module_Django_GesiBiblio.pdf. Aucune
   compilation n'est necessaire.

2. Travailler chapitre par chapitre sur Overleaf avec main-rapide.tex :
   - ouvrez main-rapide.tex ;
   - laissez une seule ligne \newcommand{\chapitrecompile}{...} active ;
   - dans l'icône Réglages (roue dentée), onglet Compiler, choisissez
     main-rapide.tex comme Main document ;
   - compilez. Le mode draft ignore les images et accelere la compilation.
   Pour afficher les images, remplacez draft par final.

3. Compiler en local avec Tectonic, TeX Live ou MiKTeX : il n'y a pas
   de limite de 10 secondes. Voir la section 3.

Le plan payant d'Overleaf porte le delai a 240 secondes, ce qui suffit
generalement pour le module complet. Le mode Fast [draft] du menu
Recompile peut aussi aider, mais il ne garantit pas de tenir en 10 s.

======================================================================
7. RAPPEL SUR LE CODE DJANGO
======================================================================

Le code présent dans le module est pédagogique et cohérent avec
Django 5.2 LTS et Python 3.12. Pour l'exécuter :

  python -m venv .venv
  .\.venv\Scripts\Activate.ps1     (Windows)
  source .venv/bin/activate         (macOS et Linux)
  python -m pip install "Django==5.2" Pillow
  django-admin startproject gesibiblio .
  python manage.py startapp catalogue
  python manage.py migrate
  python manage.py runserver

Reportez-vous aux chapitres pour le détail des fichiers et des commandes.

Bon apprentissage.
